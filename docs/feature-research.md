# Google Docs features, ranked

This note ranks features by how often they show up in Google's own collaboration research, the Docs help center, and widely cited roundups. Each line is one feature and why it ranks there. AI writing aids and Drive-only integrations (file chips that open Drive, Gmail export, Tasks sync) are called out and were not built.

1. **Real-time co-editing.** Google's Workspace research says 76% of business time in Docs is collaborative, and simultaneous editing is the first of the five behaviors they measure. [Not all collaboration is equal](https://workspace.google.com/blog/productivity-collaboration/not-all-collaboration-is-equal-heres-what-it-looks-like-in-g-suite)

2. **Sharing with permissions.** The same research lists "sharing with confidence" as a core behavior, and a usability review ranks sharing with different permissions as the top task users want. GetApp's review sample rates file sharing important for 97% of 1,003 reviewers. [Workspace blog](https://workspace.google.com/blog/productivity-collaboration/not-all-collaboration-is-equal-heres-what-it-looks-like-in-g-suite) · [UX Planet](https://uxplanet.org/usability-review-google-docs-e99a2ac93cdd) · [GetApp](https://www.getapp.com/collaboration-software/a/google-docs/)

3. **Comments, replies, and resolve.** Google calls commenting essential to how people give feedback, and the help center documents replies, resolve, and comment shortcuts (Ctrl+Alt+M, then R / J / K / E). [Use comments](https://support.google.com/docs/answer/65129)

4. **Suggesting mode.** A usability review lists "giving suggestions for edits" third, right after comments, and the shortcut list has a dedicated switch (Ctrl+Alt+Shift+X). Not built in this pass. [UX Planet](https://uxplanet.org/usability-review-google-docs-e99a2ac93cdd) · [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

5. **Version history.** The second collaboration behavior in Google's research is seeing and restoring changes. Not built as a browser in this pass; the op log is the raw material. [Workspace blog](https://workspace.google.com/blog/productivity-collaboration/not-all-collaboration-is-equal-heres-what-it-looks-like-in-g-suite)

6. **Smart chips.** Google's own tips list chips and building blocks first: people, dates, files, and dropdowns inserted with `@`. Voting chips are the emoji ballot from the smart canvas launch. File chips need Drive, so those stay out. [11 tips](https://blog.google/products-and-platforms/products/workspace/google-docs-tips/) · [Insert smart chips](https://support.google.com/docs/answer/10710316) · [Voting chips](https://workspace.google.com/blog/productivity-collaboration/more-flow-less-work-smart-canvas)

7. **Find and replace.** Roundups treat it as a daily tool, including the less obvious regular-expression mode. Shortcuts are Ctrl+F, Ctrl+H, and Ctrl+G. [MakeUseOf](https://www.makeuseof.com/google-docs-features-youre-missing-out-on/) · [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

8. **Character formatting.** Bold, italic, underline, strikethrough, superscript, subscript, font, size, text color, and highlight color are the formatting block of the official shortcut card. [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

9. **Paragraph formatting.** Headings, alignment, line spacing, indent, bulleted lists, numbered lists, and checklists (Ctrl+Shift+7 / 8 / 9) are the next block on that card. [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

10. **Links.** Insert or edit with Ctrl+K, open with Alt+Enter. [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

11. **Images and tables.** Both are first-class insert targets; building-block updates in 2024 added richer tables, while basic insert plus add/remove row and column is the everyday path. [Building blocks](https://workspaceupdates.googleblog.com/2024/11/new-building-blocks-in-google-docs.html) · [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

12. **Page breaks and horizontal lines.** Ctrl+Enter inserts a page break; horizontal lines are a standard Insert item. [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

13. **Word count.** The shortcut card lists Ctrl+Shift+C for the document or the selection. [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

14. **Paint format and clear formatting.** Copy and paste formatting are Ctrl+Alt+C / Ctrl+Alt+V; clear formatting is Ctrl+\. [Keyboard shortcuts](https://support.google.com/docs/answer/179738)

15. **Document tabs.** A 2024 Workspace launch for splitting long docs into sections. Useful, and a larger structure than this editor pass. [Document tabs](https://workspaceupdates.googleblog.com/2024/10/tabs-in-google-docs.html)

16. **Cloud file storage and multi-device access.** GetApp's review analysis rates document storage important for 97% of reviewers. That is Drive, not the editor surface. [GetApp](https://www.getapp.com/collaboration-software/a/google-docs/)

Sources for the learning-center chip flow: [Tips to edit and collaborate](https://support.google.com/a/users/answer/13004165).
